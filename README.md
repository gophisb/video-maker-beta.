# مِداد — صانع الفيديو

استوديو عربي يعمل في المتصفح لتحويل الصور والنصوص إلى فيديو، مع تحريك تدريجي وانتقالات وموسيقى خلفية.

## المزايا
- واجهة عربية RTL متجاوبة مع الهاتف والحاسوب.
- شرائح صور ونصوص، إعادة ترتيب بالسحب، وتحرير مستقل لكل شريحة.
- نسب 9:16 و16:9 و1:1، ومعدل 24 أو 30 إطاراً/ثانية.
- تحريك تدريجي للصور وانتقالات بين الشرائح.
- موسيقى خلفية متكررة مع خفض تدريجي في النهاية.
- معاينة وتصدير عبر Canvas Capture Stream وMediaRecorder.
- لا تُرفع الصور أو ملفات الصوت إلى خادم.
- دعم PWA والتخزين المؤقت لملفات التطبيق الأساسية.

## التشغيل
افتح الموقع عبر GitHub Pages أو خادم محلي. يلزم HTTPS أو localhost لدعم بعض واجهات المتصفح. أفضل توافق للتصدير عادةً في Chrome حديث.

## ملاحظات تقنية
- صيغة الملف تعتمد على ترميزات MediaRecorder المتاحة في المتصفح؛ قد يكون الناتج WebM بدلاً من MP4.
- التصدير يسجل الزمن الفعلي، لذا أبقِ الصفحة مفتوحة والشاشة مضاءة.
- لا تحفظ ملفات الوسائط في التخزين المؤقت للتطبيق؛ تظل ملفات المشروع محلية في ذاكرة الصفحة.

## النشر
يتولى GitHub Actions نشر محتويات الجذر إلى GitHub Pages عند كل تحديث لفرع `main`. من إعدادات المستودع، اجعل Pages تستخدم GitHub Actions كمصدر للنشر.
